# Resolve Merge Conflicts in Calculator Branches

## Task Brief
Practice conflict resolution by intentionally merging overlapping feature branches, resolving conflicts, and completing the merge.

## Scenario
Two team members modified the same calculator functions. Merge their branches, resolve conflicts manually, and document the resolution.

## Deliverables
- Resolved merge conflict
- Completed merge commit

## Success Criteria
- Conflict markers identified and resolved
- Merged branch tested and working
