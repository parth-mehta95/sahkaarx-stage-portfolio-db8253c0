# Create Feature Branches for Calculator Operations

## Task Brief
Build feature branches for addition, subtraction, and multiplication; practice atomic commits with clear messages on your calculator repository.

## Scenario
Your team needs three new calculator operations on separate feature branches with professional commit messages and clean history.

## Deliverables
- Three feature branches with atomic commits
- Clear commit messages documenting each operation

## Success Criteria
- Each branch has 2-3 focused commits
- Commit messages follow conventional format
