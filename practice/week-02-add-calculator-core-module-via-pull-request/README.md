Create calculator core functions (add, subtract, multiply, divide) on a feature branch and merge via pull request with code review.

Your team needs the calculator core module. Create a feature branch, implement functions, open a pull request, and merge after review.

- Merged pull request with review comments

## Success Criteria
- All four operations implemented
- Pull request reviewed and merged
